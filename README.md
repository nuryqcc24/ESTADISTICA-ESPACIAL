# ESTADISTICA-ESPACIAL
Recopilación de métodos cuantitativos y modelos de autocorrelación espacial aplicados al territorio. Incluye gestión de datos geográficos, análisis exploratorio de datos espaciales (ESDA) y flujos de trabajo con SIG y herramientas analíticas.

🌐 **Portafolio web:** https://nuryqcc24.github.io/ESTADISTICA-ESPACIAL/

## Estructura
| Carpeta | Contenido |
|---|---|
| `codigo/` | Scripts en Python (Moran, LISA, NNI, KDE, semivariograma) |
| `img/` | Capturas de trabajos en QGIS |
| `proyectos/` | Proyectos de QGIS (`.qgz`) |
| `index.html`, `style.css`, `script.js` | Página del portafolio |

## Cómo agregar un trabajo nuevo
1. Copia el archivo en la carpeta que corresponda (`codigo/`, `img/` o `proyectos/`).
2. En `index.html`, duplica una tarjeta `<div class="col-sm-6 col-lg-4 card-item">` y cambia el título, la descripción y la ruta del archivo.
3. Haz commit y push; GitHub Pages se actualiza en 1–2 minutos.
